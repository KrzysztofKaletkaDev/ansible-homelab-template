# 2. Locally-managed tunnel configuration instead of the Cloudflare dashboard

## Status

Accepted

## Context

Having decided to route ingress through a Cloudflare Tunnel
([ADR-0001](0001-cloudflare-tunnel-over-port-forwarding.md)), Cloudflare
offers two ways to configure what the tunnel does: a **remotely-managed**
tunnel, where ingress rules are edited through the Cloudflare dashboard and
pushed to the daemon, or a **locally-managed** tunnel, where `cloudflared`
reads a `config.yml` file that lives on the host and is fully owned by the
operator.

This project's whole premise is that infrastructure state lives in this Git
repository, reviewed and applied the same way as every other role — not
clicked together in a web UI that drifts silently from what's checked in.

## Decision

Use a locally-managed tunnel. `roles/cloudflared` renders `config.yml` from
a Jinja2 template (`config.yml.j2`) and deploys it to the host exactly like
every other config file in this repo, under Ansible's control and subject
to the same review process.

## Consequences

- Ingress rules for the tunnel (hostname, target service, TLS
  `originServerName`) are version-controlled, diffable, and reproducible on
  a fresh host — consistent with how every other service in this repo is
  configured.
- The tunnel's *existence* (ID, credentials, DNS route) still cannot be
  created this way — `cloudflared tunnel login` / `create` / `route dns`
  must be run manually once, outside Ansible, before this role's config can
  point at anything real. Locally-managed only moves the ingress rules into
  code; it does not remove the manual bootstrap.
- Any change to ingress routing requires a full Ansible run to take effect
  (`notify: Restart cloudflared`), instead of an instant dashboard edit —
  a deliberate slowdown in exchange for the config being reviewable.
- Losing or rotating the credentials file is a manual, out-of-band
  operation (it's Vault-encrypted, not regenerated by this role), unlike a
  remotely-managed tunnel where Cloudflare holds that state for you.
